Kugi Serif font sample

The Javascript function overflowText() reflows text from a DIV to empty DIVs respecting simple character formatting. This page shows a newspaper page layout and random boxes. The function is declarative. You create the relations of the DIVs in HTML code and then run the function to postprocess the page.

Usage

<div id="1" class="box" overflow-into="2">Lorem ipsum...</div>
<div id="2" class="box" overflow-into="3"></div>
<div id="3" class="box" overflow-into="4"></div>
<div id="4" class="box" overflow-into="5"></div>
<div id="5" class="box" ></div>
  • Add class overflow to the DIV nodes.
  • Add attribute overflow-into to he node indicating the id of the next DIV
  • Fill the first DIV and leave all subsequent DIV empty
  • Run the function overflowText() at the end of the page
  • Limitation: The algorithm works only on top level tags. You cannot nest tags. So the tags h4, br, b, i are ok, but not p with nested tags or list tags which are always nested.
